# Highlight Desktop Test v1.1.6 checkpoint — 2026-10-02

## Fixes

- Direct Reel publishing now requires a valid Website article URL before calling Meta and appends that URL to First Comment automatically.
- The direct publish dialog has a dedicated Website article URL field and blocks an unsafe publish when it is empty.
- Scheduled Reel workers also refuse to publish a Reel until its saved Website URL and First Comment match, preventing a successful Reel without the required comment link.
- Published clips continue to be removed locally only after Meta confirmation; the UI labels this state `Video đã xóa sau khi đăng thành công`.
- Website generation remains gated at 600+ words, an original-video summary, and three landscape images. The verified public sample now shows about 927 words and three 1920×1080 source frames.

## Verification

- Release tests: 176 passed, 10 subtests passed.
- Public sample: HTTP 200, three source-frame images, five total HTML images including the logo/video placeholder, about 927 visible words, and original-video summary present.
- Runtime sample: 15 published posts, all have `first_comment_status=posted`, comment IDs, and their Website URL in the saved First Comment.
