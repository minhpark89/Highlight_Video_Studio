## What changed

- Content Studio attention filter includes failed CMS, required missing Website/comment, and text LLM fallback even when package-level status is `ready`. On the October 1 local data it identified 168 of 285 packages; the old status-only filter showed three.
- Scheduling attaches existing package text for the same clip. CMS/comment repair keeps existing caption/article text and avoids an unnecessary second text generation. A failed CMS status remains visible for an explicit retry.
- A stable per-clip CMS slug is checked by GET before POST. A matching public article with the original video embed is reused; an unexpected lookup response blocks publication to avoid duplicates.
- Meta reconciliation checks the upload video ID before the candidate post ID and requires `video_status=ready`, `publishing_phase.publish_status=published`, and a Reel permalink. Relative `/reel/...` permalinks are normalized. Existing records that exhausted old post-ID attempts get a fresh bounded video-ID check.
- First comment queue deduplicates by local post ID. Post Management retains the stored Website embed status instead of replacing it with `unknown`.
